# 日麻点数计算器 - 设计文档

## 概述

为 OtakuMap 小程序新增日麻（ Japanese Mahjong / リーチ麻雀）胡牌点数计算功能。用户输入手牌和场况，系统自动分析牌型、计算符数、判定役种并输出最终点数。

## 功能范围

| 功能 | 说明 |
|------|------|
| 手牌输入 | 34种基础牌（万/筒/索/字）选择，支持14张手牌 + 宝牌指示牌 |
| 场况设置 | 场风(东南西北)、身份(亲家/子家)、胡牌方式(自摸/荣和)、本场数、供托 |
| 立直系统 | 立直、一发、双立直选项（需门前状态） |
| 宝牌计算 | 表宝牌、里宝牌（立直后揭面）、赤宝牌（自动检测）、累计宝牌 |
| 自动判定 | 系统自动分割手牌、计算符数、判定役种（用户无需手动选择） |
| 结果展示 | 符数详情、役种列表、翻数汇总、支付明细 |

## 设计风格

高级二次元风格 + 霓虹夜鸦主题，与 OtakuMap 整体风格保持一致。

## 核心算法

### 数据结构

```javascript
// 单张牌
// suit: 'm'=万子, 'p'=筒子, 's'=索子, 'z'=字牌
// value: 1-9 (数牌) 或 1-7 (字牌: 东南西北白发中)
// isRed: 是否赤牌（仅5m/5p/5s可能为赤）

const tile = { suit: 'm', value: 5, isRed: false };  // 5万
const redTile = { suit: 'p', value: 5, isRed: true }; // 赤5筒

// 面子类型
// type: 'shuntsu'=顺子, 'koutsu'=刻子, 'kantsu'=杠子
// isOpen: 是否副露（明）
// tiles: 组成牌

const meld = {
  type: 'koutsu',      // 刻子
  isOpen: false,       // 暗刻
  tiles: [tile, tile, tile],
};

// 副露信息（吃/碰/杠）
const furo = {
  type: 'pon',         // 'chi' | 'pon' | 'kan' | 'ankan' | 'kakan'
  tiles: [tile, tile, tile],
  fromWho: 'kamicha', // 'kamicha'=上家, 'toimen'=对面, 'shimocha'=下家
  calledTile: tile,   // 被叫的那张牌
};

// 手牌（完整结构）
const hand = {
  closed: [tile, ...],     // 门前手牌（不含副露）
  melds: [furo, ...],      // 副露列表
  agariTile: tile,         // 和牌张
  isTsumo: true,           // 是否自摸
};

// 场况
const situation = {
  bakaze: 'east',          // 场风: 'east' | 'south' | 'west' | 'north'
  jikaze: 'south',         // 自风: 'east' | 'south' | 'west' | 'north'
  isParent: false,         // 是否亲家（jikaze === 'east'）
  honba: 3,                // 本场数
  kyoutaku: 2,             // 供托数（立直棒数量）

  // 特殊状态
  isRiichi: false,         // 立直
  isDoubleRiichi: false,   // 双立直
  isIppatsu: false,        // 一发
  isRinshan: false,        // 岭上开花
  isChankan: false,        // 抢杠
  isHaitei: false,         // 海底摸月
  isHoutei: false,         // 河底捞鱼
  isTenhou: false,         // 天和
  isChiihou: false,        // 地和
};

// 宝牌
const dora = {
  indicators: [tile, ...],      // 表宝牌指示牌
  uraIndicators: [tile, ...],   // 里宝牌指示牌（立直和牌后揭示）
};

// 计算结果
const result = {
  // 手牌分析
  agariPattern: {
    melds: [meld, ...],    // 面子分解
    head: [tile, tile],    // 雀头
    waitType: 'ryanmen',   // 'ryanmen'=两面, 'kanchan'=嵌张, 'penchan'=边张, 'shanpon'=双碰, 'tanki'=单骑
  },

  // 符数明细
  fuDetails: {
    base: 20,              // 副底
    menzenRon: 10,         // 门前荣和加符
    tsumo: 2,              // 自摸加符
    head: 2,               // 雀头符
    melds: [               // 面子符
      { name: '幺九暗刻', fu: 8 },
      { name: '中张明刻', fu: 2 },
    ],
    wait: 2,               // 听牌型符
    total: 40,             // 合计（进位后）
  },

  // 役种明细
  yakuList: [
    { name: '立直', han: 1, isYakuman: false },
    { name: '断幺九', han: 1, isYakuman: false },
    { name: '一盃口', han: 1, isYakuman: false },
  ],

  // 宝牌明细（三个维度各自独立统计，互不重叠，相加得 total）
  doraCount: {
    dora: 2,               // 表宝牌数（指示牌命中，不含赤）
    uraDora: 1,            // 里宝牌数（仅立直时计算，不含赤）
    akaDora: 1,            // 赤宝牌数（tile.isRed，独立维度）
    total: 4,              // 宝牌合计 = dora + uraDora + akaDora
  },

  // 点数计算
  han: 3,                  // 役种翻数（不含宝牌）
  totalHan: 7,             // 总翻数（含宝牌）
  fu: 40,                  // 符数
  basePoints: 3000,        // 基本点
  limitName: 'haneman',    // null | 'mangan' | 'haneman' | 'baiman' | 'sanbaiman' | 'yakuman' | 'double_yakuman'

  // 支付明细
  payment: {
    total: 12000,          // 和牌者获得总点数
    fromParent: 6000,      // 亲家支付（自摸时）
    fromChild: 3000,       // 子家支付（自摸时）
    fromDealer: null,      // 放铳者支付（荣和时）
    honbaBonus: 300,       // 本场加算
    kyoutakuBonus: 2000,   // 供托获得
  },
};
```

### 符数计算规则

#### 基础符数

| 项目 | 符数 | 说明 |
|------|------|------|
| 副底 | 20符 | 所有和牌的基础符数 |
| 门前荣和 | +10符 | 门前清状态下荣和（非自摸） |
| 自摸 | +2符 | 自摸和牌（平和自摸除外） |

#### 雀头符数

| 雀头类型 | 符数 | 说明 |
|----------|------|------|
| 数牌/客风 | 0符 | 普通雀头无符 |
| 役牌（三元牌） | 2符 | 白、發、中 |
| 自风牌 | 2符 | 与玩家座位风相同 |
| 场风牌 | 2符 | 与当前场风相同 |
| 连风牌 | 4符 | 同时是自风和场风（如东场东家的东） |

#### 面子符数

| 面子类型 | 中张(2-8) | 幺九(1,9,字牌) |
|----------|-----------|----------------|
| 顺子 | 0符 | 0符 |
| 明刻 | 2符 | 4符 |
| 暗刻 | 4符 | 8符 |
| 明杠 | 8符 | 16符 |
| 暗杠 | 16符 | 32符 |

#### 听牌型符数

| 听牌型 | 符数 | 说明 |
|--------|------|------|
| 两面听 | 0符 | 如 23 听 1 或 4 |
| 双碰听 | 0符 | 如 AA BB 听 A 或 B |
| 嵌张听 | 2符 | 如 13 听 2 |
| 边张听 | 2符 | 如 12 听 3 或 89 听 7 |
| 单骑听 | 2符 | 如 A 听 A 做雀头 |

#### 特殊符数规则

| 情况 | 符数 | 说明 |
|------|------|------|
| 平和自摸 | 20符 | 固定20符（不加自摸2符） |
| 平和荣和 | 30符 | 固定30符 |
| 七对子 | 25符 | 固定25符（不进位） |
| 喰い替え（副露平和型荣和） | 30符 | 最低30符保底 |

### 点数计算公式

#### 基本点计算

```
基本点 = 符数 × 2^(翻数+2)
```

计算后向上取整到百位（切り上げ）。

#### 基本点上限（满贯系统）

| 翻数 | 名称 | 基本点 | 亲家自摸(×2×3) | 亲家荣和(×6) | 子家自摸(亲×2+子×1×2) | 子家荣和(×4) |
|------|------|--------|----------------|--------------|----------------------|--------------|
| 3翻30符 / 4翻25符 以下 | 通常 | 按公式 | 按公式 | 按公式 | 按公式 | 按公式 |
| 3翻60符 / 4翻30符 / 5翻 | 满贯 | 2000 | 4000 all | 12000 | 2000/4000 | 8000 |
| 6-7翻 | 跳满 | 3000 | 6000 all | 18000 | 3000/6000 | 12000 |
| 8-10翻 | 倍满 | 4000 | 8000 all | 24000 | 4000/8000 | 16000 |
| 11-12翻 | 三倍满 | 6000 | 12000 all | 36000 | 6000/12000 | 24000 |
| 13翻+ / 役满 | 役满 | 8000 | 16000 all | 48000 | 8000/16000 | 32000 |
| 双倍役满 | 双倍役满 | 16000 | 32000 all | 96000 | 16000/32000 | 64000 |

### 支付规则

#### 荣和（ロン）

放铳者单独支付全部点数：
- 基本点 × 4（子家放铳给子家）
- 基本点 × 6（子家放铳给亲家，或亲家放铳给子家）

#### 自摸（ツモ）

三家分摊支付：
- 亲家自摸：每位子家支付 基本点 × 2
- 子家自摸：亲家支付 基本点 × 2，其他子家各支付 基本点 × 1

#### 本场加算

每本场额外支付：
- 荣和：+300点（放铳者支付）
- 自摸：+100点 × 3（每人多付100点）

#### 供托（立直棒）

和牌者获得场上所有供托点数（每根1000点）。

## 宝牌计数约定

宝牌分三个**互不重叠**的维度统计，最终 `total = dora + uraDora + akaDora`：

| 维度 | 来源 | 计数方式 | 计入条件 |
|------|------|----------|----------|
| 表宝牌 dora | 表宝牌指示牌的下一张 | `countDora(手牌, 表指示牌)` 命中张数 | 总是 |
| 里宝牌 uraDora | 里宝牌指示牌的下一张 | `countDora(手牌, 里指示牌)` 命中张数 | 仅立直时 |
| 赤宝牌 akaDora | 牌自身 `isRed` 标记 | 手牌中 `isRed === true` 的张数 | 总是 |

实现要点（修复后）：

- `config/tiles.js` 的 `countDora` **只统计指示牌命中的宝牌**，不含赤宝牌——赤宝牌是独立维度，否则会被表/里宝牌重复计入。
- `engine.js` 的 `countAllDoraForHand` 三维度各自独立统计后相加，不做任何减法补偿。
- 非立直时，即使传入了里宝牌指示牌也一律忽略（`uraDora = 0`）。
